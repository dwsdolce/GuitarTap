# Appendix A — Keyboard Shortcuts (macOS)

| Shortcut | Action |
|----------|--------|
| ⌘, | Settings |
| ⌘S | Save Measurement… |
| ⌘E | Export Spectrum Image… |
| ⇧⌘E | Export PDF Report… |
| ⌘0 | Auto dB |
| ⌘\` | Cycle Annotations |
| ⌘M | Show Metrics |
| ⌘L | Show Measurements |

<div class="note">Keyboard shortcuts apply to the macOS native app only. The Python desktop app on Windows and Linux uses equivalent menu items; shortcut keys may differ by platform.</div>
