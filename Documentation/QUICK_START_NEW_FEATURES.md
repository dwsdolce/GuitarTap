# Quick Start: New Save & Import Features

## What Changed?

Your GuitarTap app now **automatically saves chart images** with every measurement and can **fully recreate** any saved measurement.

## The 3 Main Features

### 1. 📸 Auto-Save Chart Images

**What:** When you click "Save", the app automatically captures a PNG image of the current spectrum plot.

**How:**
1. Tap guitar and collect measurements
2. Click **"Save"** button
3. Fill in location/notes
4. Click **"Save"** in sheet
5. ✨ **Done!** - Image is saved automatically

**No extra button to click** - it just happens!

---

### 2. 📥 Import Measurements

**What:** Import JSON files to restore measurements with all their data.

**How:**
1. Open **"Measurements"**
2. Click **"Import"** button
3. Select a JSON file
4. ✅ Success! Measurements appear in list

**Includes:** Peaks, images, spectrum, annotations, everything!

---

### 3. 🔄 Load Measurements (Recreate Plots)

**What:** Click "Load" to recreate the exact plot from a saved measurement.

**How:**
1. Open **"Measurements"**
2. Tap/click a measurement
3. Click **"Load"** button (download icon)
4. Confirm
5. ✨ Main view shows the exact saved state!

**Perfect for:** Comparing before/after, reviewing history, sharing state

---

## Visual Indicators

In the measurements list, you'll now see icons:
- **📷 Blue photo icon** = Has chart image saved
- **〰️ Green waveform icon** = Has full spectrum data

---

## Example Workflows

### Document a Build

```
1. Measure at each stage
2. Save with descriptive names
   → Images auto-save
3. Export all as JSON for backup
4. Use images in build journal
```

### Compare Adjustments

```
1. Save "before" measurement
   → Image and spectrum saved
2. Make adjustment
3. Save "after" measurement
4. Load "before" to compare side-by-side
5. Export both for records
```

### Share with Someone

```
1. Save your measurement
   → Complete data saved
2. Export as JSON
3. Send file
4. They import it
5. They click "Load" 
   → See exactly what you saw!
```

## What Gets Saved?

Every measurement now includes:
- ✅ All detected peaks
- ✅ **Chart image (PNG)** ← NEW!
- ✅ **Complete spectrum data** ← NEW!
- ✅ **Your annotation positions** ← NEW!
- ✅ Current zoom settings ← NEW!
- ✅ Tap location and notes
- ✅ Decay time and ratios

---

## Quick Tips

1. **Always fill in tap location** - Makes finding measurements easier
2. **Arrange labels before saving** - Positions are preserved
3. **Set zoom before saving** - Image captures current view
4. **Export regularly** - JSON files are your backup
5. **Use Load feature** - Compare measurements over time

---

## Buttons You'll Use

### Main View
- **Save** - Captures everything (including image)
- **Measurements** - Opens measurement list

### Measurements List
- **Import** - Load JSON file
- **Export All** - Save all to JSON
- **[Tap measurement]** - Open details

### Measurement Details
- **Load** - Recreate plot in main view
- **Export JSON** - Save single measurement
- **Export Chart Image** - Render new image
- **Saved Image** (if exists) - Share original image
